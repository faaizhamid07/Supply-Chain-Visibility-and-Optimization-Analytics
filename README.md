# Supply Chain Visibility System with Optimization Analytics

An end-to-end supply chain analytics project developed as part of the **Infosys Virtual Internship**. The project focuses on transforming supply-chain data into actionable insights across inventory, delivery, suppliers, transportation, and warehouse operations.

## Project Overview

Modern supply chains generate large volumes of operational data across procurement, inventory, transportation, suppliers, deliveries, and warehouses. This project applies data modelling, analytics, and business intelligence techniques to improve visibility and support data-driven decision-making.

### Objectives

- Build a structured data model for supply-chain analytics.
- Analyze inventory levels, demand, and delivery performance.
- Evaluate supplier and transportation performance.
- Analyze warehouse operations and efficiency.
- Develop interactive dashboards for decision support.
- Translate operational data into practical business insights.

## Technology Stack

| Area | Technology |

## Project Workstreams

### 1. Data Modelling
Establishes the analytical structure required to connect supply-chain entities and support consistent reporting.

### 2. Inventory & Delivery Analytics
Focuses on inventory visibility, stock behaviour, delivery performance, and operational trends.

### 3. Supplier & Transportation Analytics
Examines supplier performance and transportation-related metrics to identify inefficiencies and improvement opportunities.

### 4. Warehouse Analytics
Analyzes warehouse-level operations and performance to support capacity, efficiency, and process decisions.
